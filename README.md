# Horde Highway

Lane-runner zombie shooter, built twice: once for the web (three.js) and once
in Godot 4. Grow your squad through math gates, shoot gates to improve them,
dodge traps, and fight five enemy types and a boss.

- **Play in the browser:** https://mitovoid-ai.github.io/HordeHighway/
- **Android APKs:** [latest release](https://github.com/Mitovoid-AI/HordeHighway/releases/latest)

| Folder | What it is |
|---|---|
| [`html5-game/`](html5-game/) | three.js + cannon-es version; also packaged as an Android WebView APK (`android/`) |
| [`godot-game/`](godot-game/) | Godot 4.7 version with Android export preset |
| [`docs/`](docs/) | GitHub Pages site: landing page + playable web build (`docs/play/`) |
| [`apk/`](apk/) | Install guide and test notes for the APKs |
| [`zombie-survival-design.md`](zombie-survival-design.md) | Game rules and the reverse-engineering findings they are based on |
